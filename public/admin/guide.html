写作，然后发布。

文章

登录 GitHub → 文章 → 新建。填写标题、摘要、发布时间和正文。正文支持可视化与 Markdown 编辑，也可以插入图片。标签、封面和精选按需要填写。

草稿与发布

“保存”将内容提交到私有仓库的草稿分支；“发布”合并到内容主分支，等待自动构建成功后网站才更新。编辑器的本地恢复只在当前设备有效，换设备前请保存。

撤回文章或项目文档时勾选“暂不公开 / 撤回”并发布修改。删除文章后也需要成功构建才能清除上线页面。未来发布时间依赖私有仓库的每小时调度，可能延迟约一小时或更久，不保证精确到分钟。

项目文档

进入“项目文档”→ 新建。填写标题，使用“导入 README / Markdown”选择 .md 或 .markdown 文件，或直接编辑正文。导入只填入正文，文件中的 YAML 信息不自动填写表单；请核对标题、摘要和发布时间。保存并发布后，项目列表会进入站内详情阅读。

也可将 Markdown 文件放入私有内容仓库 projects/，普通 README 无需 YAML。独立插图请上传到媒体库，更新正文中的图片路径；导入 Markdown 不会同时上传其相对引用的本地图片。

个人资料与足迹

进入“个人资料与足迹”，维护头像、签名与城市故事；项目文档在独立栏目中管理。经纬度按经度在前、纬度在后填写。城市列表为空时，关于页会隐藏地图。

这些内容共用原有设置文件。摄影、音乐、碎碎念和游戏已停止展示；旧原始内容没有在这次界面简化中主动清除，后续请通过私有仓库历史查阅。

图片与故障处理

文章和头像上传的图片在发布时会限制最长边为 1920px，转换为 WebP 并去除 EXIF。原图请自行备份。发布失败时查看私有内容仓库 Actions；旧网站会继续保留。

关于页正文、站点导航和翻译仍在源码中维护。RSS 是静态订阅文件，不是邮件发送服务。服务器回滚与备份说明见源码仓库 docs/annual-2026.md。
