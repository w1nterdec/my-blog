写一篇随笔

登录 GitHub → 随笔 → 新建。填写标题、摘要、时间、标签，可在正文切换可视化与 Markdown，随时穿插图片。封面和置顶是可选项。

草稿、恢复与发布

“保存”将内容提交到私有仓库的草稿分支，其他访客看不到。编辑器有当前设备的本地恢复备份，但换设备前仍应点击保存。发布前用右侧预览检查；“发布”合并到私有内容主分支，自动构建成功后才会更新网站。未成功构建时旧网站继续可用。

若要撤回，勾选“暂不公开 / 撤回”并发布这个修改。删除文章也需要等待成功构建，清除已上线页面。发布时间设为未来可排期；调度每 15 分钟检查，不会提前公开，可能延迟约一小时，GitHub 调度忙碌时可能更久。

摄影、音乐与碎碎念

进入“生活与站点”。摄影上传精选展示图，填写日期、城市、器材和故事；在列表拖动排序，第一张作为首页封面。原图由你自行备份，网站发布的是限制尺寸、去除 EXIF 的 WebP，展示不加水印。可见图片仍可能被保存，版权声明不能彻底阻止复制。

音乐只展示封面与跳转，不播放。粘贴 Spotify 或 QQ 音乐分享链接，不填写时不会出现空链接。没有封面时用文字卡片。碎碎念可以设为仅在孤岛展示，但孤岛是公开彩蛋，不能存放隐私。

自动备份与失败恢复

GitHub 的私有版本历史记录每次保存和发布，可撤回错误更改；它不是独立备份。独立离线备份与服务器回滚操作见源码仓库的年度维护文档。发布失败请查看私有内容仓库 Actions；GitHub 账户设置中开启工作流失败通知。

RSS 是静态订阅文件，不是邮件订阅，不会额外运行发送服务。
